# Glossary

Terms used in the brief, the client report and the commitments.

| Term | Meaning in this study |
|---|---|
| **Challan** | Delivery challan: the dispatch document raised when goods leave the distributor. Challan lines are the source of every volume figure here. |
| **Dispatch** | Units shipped on a challan. Used as the demand measure; it is not the same as end-customer sales. |
| **FY** | Indian financial year, April to March. FY 2012–13 = Apr 2012 – Mar 2013. |
| **PC- code** | The client's own-brand part code, shown with the neutral prefix `PC-` for anonymisation. |
| **PC-86207** | The Swift / Swift Dzire AC condenser at the centre of the study. |
| **PC-86539** | Candidate successor code. Its descriptions cover Swift, Ertiga and SX4, so its volume is not Swift-only. |
| **Fitment** | The vehicle model, generation and variant a part is built to fit. |
| **Multi-application code** | A part code whose descriptions name more than one vehicle. Its total must be split by fitment before it is used as model-level demand. |
| **OEM reference** | The vehicle manufacturer's part number, used to confirm fitment. |
| **Code transition** | Demand moving from one part code to another, e.g. when a vehicle generation changes. A hypothesis here until line-level evidence confirms it. |
| **Supplier substitution** | A distributor buying the same fitment from another supplier. Not provable from one SKU's decline alone. |
| **Distributor concentration** | The share of a code's volume taken by its largest distributors. |
| **Vehicle cohort** | Vehicles sold in the same period, used to estimate when they reach the AC repair and replacement age. A demand indicator, not a sales volume. |
| **Observation vs hypothesis** | An observation is read directly from the data. A hypothesis explains it and stays open until the evidence listed in the brief is checked. |
| **Master list** | The client's list of approved condenser codes and the vehicle each fits (219 codes). The reference every other code is matched to. |
| **Normalised code** | A code in upper case with only letters and digits, so `PC-86539 Q5` and `PC86539-Q5` compare equal. |
| **Code map** | The table recording, for each old or variant code, which master code it belongs to and the client's decision (*Auto*, *Accept*, *New part*, *Ignore*). |
| **Grain** | The level one row represents. Phase 2 stores one row per part per month. |
| **FY quarter** | Quarter of the financial year: Q1 = Apr–Jun, Q2 = Jul–Sep, Q3 = Oct–Dec, Q4 = Jan–Mar. |
| **Cut-over** | The month the series switches source: challan register up to Mar 2019, yearly Excel files from Apr 2019. |
| **Q5 grade** | A higher-grade variant of a condenser code, written with a `Q5` suffix. Kept as its own part. |
| **Provisional** | A figure that has passed the load checks but still depends on an open client confirmation. |
