## How this folder is kept

- Drafts are **kept unchanged** once committed, so the evolution of the question stays traceable. Revisions are added as new numbered files (`02-…`, `03-…`), never by overwriting.
- The first draft framed the problem at brand level. The question was later narrowed to a single SKU, *why did PC-86207 fall from ~580 to ~40 units a year?*, which is what the [README](../README.md) and [client report](../deliverables/client-ready-report.md) now answer.
- Raw challans, distributor transactions and price lists are not stored here (see `.gitignore`).
